# Reviewer Test Instructions

The extension is an internal companion to the Acxxel procurement application.

1. Sign in to the supplied HTTPS Acxxel test environment as a Bid Analyser.
2. Open an admin-approved Desktop bid with an assigned model.
3. Select **Upload to GeM**.
4. Confirm that a new GeM login tab opens.
5. Sign in to GeM manually and navigate to Catalogue > Add New Offering.
6. Open the applicable Desktop category and each catalogue step.
7. Confirm that approved values are populated and unresolved fields are flagged.
8. Confirm that final submission is not performed by the extension.

The reviewer account and reachable test URLs must be entered privately in the
Chrome Web Store **Test instructions** tab. Do not place credentials in the ZIP
or public listing.
